# 工作区设置功能

## 功能说明

HyperChat 现在支持工作区级别的设置管理，每个工作区都可以有独立的配置。

## 使用方法

### 1. 打开设置
- 在工作区标签页右侧的三点菜单中，点击"工作区设置"
- 或者右键点击工作区标签，选择"设置"

### 2. 设置分类
设置被分为以下几个类别：

#### 外观设置
- **夜间模式**: 开启/关闭夜间模式
- **主题**: 选择浅色、深色或自动主题
- **字体大小**: 小、中、大三种选择
- **界面语言**: 中文/英文

#### 编辑器设置
- **自动保存**: 是否启用自动保存
- **自动保存延迟**: 保存延迟时间（毫秒）
- **自动换行**: 是否启用自动换行
- **Tab 大小**: 设置缩进大小

#### AI 设置
- **默认模型**: 设置默认的 AI 模型
- **默认 Agent**: 设置默认使用的 Agent
- **温度参数**: AI 响应的随机性设置
- **最大 Token 数**: 限制 AI 响应的最大长度
- **流式响应**: 是否启用流式输出

#### 高级设置
- **启用遥测**: 是否收集使用数据
- **调试模式**: 开启调试信息
- **实验性功能**: 启用实验性功能

### 3. 设置操作
- **保存**: 保存当前更改
- **重置**: 恢复默认设置
- **导出**: 将设置导出为 JSON 文件
- **导入**: 从 JSON 文件导入设置

## 文件存储

设置文件保存在各工作区的 `.hyperchat/settings.jsonc` 文件中，支持 JSON 注释格式。

## 自动生成的 Schema

系统会自动生成 `settings.schema.json` 文件，在支持的编辑器中可以获得智能提示和验证。

## 设置同步

当修改外观设置时，界面会立即应用更改，如夜间模式切换等。
